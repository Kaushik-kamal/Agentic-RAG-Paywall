# Learning Science and Instructional Design

## Retrieval practice

Testing is not merely assessment; it is one of the most effective learning
interventions known. Recalling information from memory strengthens the retrieval
route far more than re-reading the same material, an effect robust across ages,
subjects, and formats. Re-reading produces fluency that feels like learning and
predicts performance poorly.

The effect is larger when retrieval is effortful but successful. Immediate feedback
after a failed attempt converts the failure into learning rather than reinforcing
the error.

## Spacing and interleaving

Distributing study across sessions produces markedly better long-term retention than
massing the same total time. The optimal gap scales with the retention interval:
roughly 10–20% of the time until the material is needed.

Interleaving different problem types within a session impairs performance during
practice but improves later transfer, because it forces the learner to select a
strategy rather than merely execute a known one. Blocked practice feels more
productive and teaches less — a second instance of the same illusion.

## Cognitive load

Working memory holds only a few elements at once. Instructional design should
minimise **extraneous load** (poor layout, split attention, redundant text
duplicating narration) so capacity remains for **germane load** — the effortful
schema construction that constitutes learning.

The **worked-example effect** shows novices learn more from studying solved problems
than from solving equivalent problems themselves. The effect reverses as expertise
grows: for experts, worked examples become redundant and problem solving is
superior. Designing for the wrong expertise level is the most common error.

## Feedback

Effective feedback tells the learner where they are going, how they are doing, and
what to do next. Feedback focused on the task and the process outperforms feedback
focused on the self; praise directed at the person can reduce subsequent performance
by shifting attention from the task to self-evaluation.

Delayed feedback often beats immediate feedback for retention, since immediate
correction can pre-empt the retrieval attempt that produces the learning.

## Assessment design

Formative assessment informs instruction; summative assessment certifies attainment.
The same instrument can serve both roles only if the stakes do not distort
behaviour.

Validity is not a property of a test but of the inferences drawn from it. A reliable
test measures something consistently; whether it measures the intended construct is
a separate question, and reliability without validity is precise measurement of the
wrong thing.
